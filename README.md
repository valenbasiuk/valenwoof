# valenwoof

bot simple de twitch con funciones similares a nightbot/fossabot, pero con la api de ranked y spotify.

## localmente

**requisitos**: rust (stable) y cuenta en supabase



1. clonar el repo

```bash
git clone https://github.com/valenbasiuk/valenwoof.git
cd valenwoof
```

2. copiar el archivo de ejemplo y completar las variables

```bash
cp .env.example .env
# editar .env con tus credenciales reales
```

3. test

```bash
cargo run
```

## entorno

ver [.env.example](.env.example) para la lista completa con descripcion de cada variable.
